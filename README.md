## About

FuelIQ Elite is an AI fitness and nutrition coach built for Arabic and English
speakers, with a regional food database that covers dishes from across the Arab
world.

The App Store requires every app to publish a support page, a privacy policy and
terms of use at public URLs. This repository hosts those pages on GitHub Pages.

These are the URLs entered in App Store Connect. Renaming a file breaks the link
the App Store shows to users, so keep the file names unchanged.

## Updating

Edit the HTML file and push to `main`. GitHub Pages republishes the site
automatically within a minute or two. Each page is a single self-contained file
with inline CSS and no build step.
